# Shared Folder Access Denied

Document ID: KB-FILE-012
Organization: NovaTech Solutions
Version: 1.0
Effective Date: 2026-10-01

## Overview
This article explains shared folder access denied and provides
approved initial troubleshooting guidance.

## Common Symptoms
- Access denied when opening a shared folder

## Possible Causes
- Missing permission
- Authentication issue

## Safe Troubleshooting Steps
1. Verify the intended folder
2. Sign in using the approved account
3. Request an authorized access review

## Safety Guidance
- Never share passwords or MFA codes.
- Never disable company security controls.
- Do not perform unauthorized system changes.

## Escalation
Contact the responsible IT service team if the
problem persists or affects multiple users.
