# Backup Failure Notification Guide

Document ID: KB-BKP-015
Organization: NovaTech Solutions
Version: 1.0
Effective Date: 2026-10-01

## Overview
This article explains backup failure notification guide and provides
approved initial troubleshooting guidance.

## Common Symptoms
- Backup monitoring reports failure

## Possible Causes
- Backup job error
- Storage availability issue

## Safe Troubleshooting Steps
1. Review approved backup alert details
2. Record the affected system
3. Escalate to Infrastructure Operations

## Safety Guidance
- Never share passwords or MFA codes.
- Never disable company security controls.
- Do not perform unauthorized system changes.

## Escalation
Contact the responsible IT service team if the
problem persists or affects multiple users.
