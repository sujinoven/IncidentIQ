
# Endpoint Security Policy

Document ID: POL-END-003
Organization: NovaTech Solutions
Version: 1.0
Owner: Endpoint Support
Effective Date: 2026-10-01

## 1. Purpose
Protect company laptops, desktops, and mobile devices.

## 2. Scope
Applies to employees and contractors using company-managed devices.

## 3. Requirements
- Full-disk encryption must remain enabled.
- Endpoint protection software must remain active.
- Operating system security updates must be installed through approved processes.
- Devices must automatically lock after 10 minutes of inactivity.
- Lost or stolen devices must be reported immediately.

## 4. Prohibited Actions
- Disabling endpoint protection.
- Installing unauthorized software.
- Sharing company devices with unauthorized users.
- Removing security management software.

## 5. Incident Reporting
Suspected malware, device theft, and security alerts must be reported to IT Support.

## 6. Escalation
Endpoint Support investigates device issues.
Security Operations handles suspected compromise.
