
# IT Change Management Policy

Document ID: POL-CHG-006
Organization: NovaTech Solutions
Version: 1.0
Owner: Platform Engineering
Effective Date: 2026-10-01

## 1. Purpose
Reduce operational risk when modifying production systems.

## 2. Scope
Applies to production configuration, infrastructure, and application changes.

## 3. Change Requirements
- Production changes must have an approved change record.
- Changes must include a documented impact assessment.
- A rollback plan must be prepared before implementation.
- Changes must be tested in an appropriate environment.
- Implementation results must be recorded.

## 4. Emergency Changes
Emergency changes require approval from the designated incident or change authority.
The emergency justification must be documented.

## 5. Prohibited Actions
- Making unauthorized production changes.
- Disabling security controls without authorization.
- Executing unreviewed changes outside approved procedures.

## 6. Escalation
High-risk changes must be reviewed by the responsible service owner and change authority.
