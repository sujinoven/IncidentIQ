
# Corporate VPN Access Policy

Document ID: POL-VPN-001
Organization: NovaTech Solutions
Version: 1.0
Owner: Network Operations
Effective Date: 2026-10-01

## 1. Purpose

Establish security requirements for accessing NovaTech
Solutions' internal resources through the corporate VPN.

## 2. Scope

Applies to all employees and authorized contractors
who access company resources remotely.

## 3. Requirements

- Users must use the company-approved VPN client.
- Multi-factor authentication (MFA) is mandatory.
- VPN credentials must not be shared.
- Devices must comply with endpoint security requirements.
- Users must report repeated authentication failures
  to IT Support.

## 4. Prohibited Actions

- Sharing VPN credentials with another person.
- Disabling or bypassing MFA.
- Disabling certificate validation.
- Using unauthorized VPN clients.

## 5. Incident Reporting

Users experiencing VPN connection failures must
contact IT Support or create a support ticket.

## 6. Escalation

IT Support may investigate connectivity issues.
Changes to VPN gateway certificates or security
configuration require approval from authorized
administrators.
